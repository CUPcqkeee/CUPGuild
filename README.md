# 🛡️ CUPGuild

Discord-бот для управления кланами, их участниками и общей экономикой. Интерфейс построен вокруг интерактивных меню: кнопки, списки и формы обновляют меню, а результат действий приходит отдельным сообщением.

> Проект использует [disnake](https://docs.disnake.dev/) и SQLite. Все пользовательские команды и игровые действия ориентированы на русский язык.

## ✨ Возможности

- **Кланы:** создание, поиск, вступление, выход и управление составом
- **Ранги и права:** пять стандартных ролей — Владелец, Заместитель, Офицер, Ветеран и Участник; владелец настраивает права рангов
- **Настройки клана:** название, тег, цвет и открытый или закрытый набор
- **Discord-структура:** при создании клана бот создаёт роль и приватную категорию с новостным каналом, чатом и тремя голосовыми каналами
- **Экономика:** балансы игроков, ежедневная награда, работа, переводы, казна и клановый доход
- **События:** создание событий, запись участников и распределение награды
- **Клановые войны:** вызовы другим кланам, принятие или отклонение и учёт результата
- **Профили и рейтинг:** уровень, XP, баланс, клан и аватар игрока
- **SQLite:** игровые данные сохраняются локально

## 📋 Требования

- Python 3.10 или новее
- Discord-приложение и токен бота
- Права бота на просмотр каналов, отправку сообщений и эмбедов, а также управление ролями и каналами

Роль бота должна находиться выше создаваемых клановых ролей в настройках ролей Discord-сервера.

## 🚀 Установка и запуск

Откройте PowerShell в корневой папке проекта и выполните:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

Создайте в корне проекта файл `.env` и добавьте токен бота:

```dotenv
DISCORD_TOKEN=вставьте_сюда_токен_бота
```

Токен можно получить в [Discord Developer Portal](https://discord.com/developers/applications). Пригласите приложение на сервер с OAuth2-областями `bot` и `applications.commands`, а также необходимыми правами.

Настройте `settings.json` и запустите бота:

```powershell
python main.py
```

При первом запуске SQLite-база автоматически создаётся по пути `data/clans.sqlite3`.

### Быстрая регистрация команд для тестового сервера

Укажите ID сервера в `bot.test_guild_ids` в `settings.json`:

```json
"bot": {
  "test_guild_ids": [123456789012345678]
}
```

Команды будут зарегистрированы для указанного сервера. Пустой список включает глобальную регистрацию команд Discord, которая может обновляться дольше.

## 🎮 Команды и меню

- `/clan` — открыть главное меню кланов
- `/profile` — посмотреть свой профиль
- `/profile игрок: @участник` — посмотреть профиль другого игрока

Дальнейшие действия доступны в кнопочном интерфейсе. Навигация изменяет основной эмбед меню, а успешные и неуспешные игровые действия показывают отдельный приватный эмбед.

### Кланы и роли

В клане предусмотрены пять рангов: **Владелец**, **Заместитель**, **Офицер**, **Ветеран** и **Участник**. Владелец может назначать ранги и настраивать права доступных рангов. Владелец сохраняет полный доступ к управлению кланом.

В меню клана можно менять название, тег, цвет и статус набора. Закрытые кланы не показываются в поиске и недоступны для вступления.

При создании клана бот создаёт роль с названием тега и приватную категорию вида `🛡️・ТЕГ — Название`, в которой находятся:

- канал новостей
- текстовый чат
- три голосовых канала

Участники клана получают клановую роль. В канале новостей участники могут читать сообщения, а писать — владелец и заместители. При изменении ранга права на отправку сообщений обновляются. При роспуске клана бот удаляет созданные роль, категорию и каналы.

### Экономика, события и войны

- Ежедневная награда и работа доступны из раздела экономики
- Перевод монет выполняется через форму в меню
- Участники с нужным правом могут получать клановый доход; средства также поступают в казну
- События позволяют записывать участников и выдавать награды с XP
- Войны позволяют отправлять вызовы другим кланам, принимать или отклонять их и фиксировать результат
- Профиль показывает аватар, уровень, XP, баланс и информацию о клане

Доступные награды, ограничения и задержки настраиваются в `settings.json`. Права проверяются при выполнении действия, а не только при отображении кнопок.

## ⚙️ Настройки

`settings.json` — основной файл конфигурации проекта:

| Раздел | Назначение |
| --- | --- |
| `bot` | ID тестовых серверов для регистрации команд |
| `database` | путь к файлу SQLite |
| `clans` | ограничения на название, тег, описание и число участников |
| `economy` | валюта, награды, XP, задержка работы, доход клана и ставка войны |
| `ui` | цвета эмбедов, тайм-аут меню и лимиты списков |

Файл `.env` предназначен для секретов и не должен попадать в Git. Не публикуйте токен бота и немедленно перевыпустите его в Developer Portal, если он оказался доступен посторонним.

## 🛠️ Если что-то не работает

- **Бот не запускается:** проверьте наличие `DISCORD_TOKEN` в `.env` и корректность JSON в `settings.json`
- **Клан не создаётся:** убедитесь, что у бота есть права на управление ролями и каналами, а его роль выше клановой
- **Команды не появились:** проверьте `bot.test_guild_ids`; глобальная регистрация Discord может занять больше времени
- **Меню перестало реагировать:** выполните команду заново, чтобы открыть новое меню; интерактивные сообщения имеют ограниченный срок действия
- **База не создаётся:** проверьте, что у процесса есть права на запись в папку проекта
